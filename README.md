# Orbit

Landing page built with **Vite + React + TypeScript + Tailwind CSS v4 + shadcn/ui** and Framer Motion.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build -> dist/
```

- Content: `src/App.tsx`
- Theme tokens: `src/index.css`
- Add shadcn components: `npx shadcn@latest add <component>` (`components.json` is preconfigured)

## Deploy

Import the repo in Vercel. It auto-detects Vite (`vercel.json` pins the build settings).
